# Diomedes Mateo

**Desarrollador de bots de Discord & sistemas para comunidades de Minecraft**

---

### Sobre mí

Me especializo en construir bots de Discord robustos y escalables orientados a comunidades de servidores de Minecraft. Trabajo con Python (`discord.py`), bases de datos SQLite/PostgreSQL, y me enfoco en sistemas de moderación, tickets, economía, niveles y herramientas de staff.

### Tecnologías

- **Lenguajes**: Python, JavaScript
- **Discord**: discord.py, slash commands, Components V2, persistent views
- **Bases de datos**: SQLite (aiosqlite), diseño de esquemas relacionales
- **Otras**: Pillow (generación de imágenes), mcstatus, asyncio

### Proyectos destacados

- **MineOrbit Discord Bot** — Bot completo para gestión de comunidad Minecraft: sistema de tickets avanzado, moderación, giveaways, torneos, voice hubs, verificación y más.
- Sistemas de logros, economía y niveles con generación dinámica de tarjetas.
