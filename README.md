### 👤 Sobre mí

Desarrollador especializado en **bots de Discord** para comunidades de Minecraft.  
Construyo sistemas de tickets, moderación, economía, niveles y herramientas de staff usando Python y `discord.py`.

- 🎮 Enfoque en servidores de Minecraft  
- 🛠️ Automatización y gestión de comunidades  
- 📚 Bases de datos y lógica de negocio compleja  

<br>

### 🛠️ Stack principal

| Área              | Tecnologías                          |
